# Aplikasi Pembantu SPJ BOS: Rencana Pembangunan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Satu layar untuk melihat kegiatan BOS dua sekolah per bulan beserta berkas yang kurang, lalu mengunduh satu PDF SPJ per sekolah per bulan.

**Architecture:** Laravel monolit dengan Inertia + Svelte. PDF anggaran dibaca per posisi teks menjadi `AnggaranTerbaca`, lalu disimpan sebagai baris `Kegiatan`. Status berkas selalu dihitung, tidak disimpan. PDF bulanan dipisah menjadi penyusun tata letak murni (`TataLetakPdf`) dan penggambar (`PdfBulanan`) supaya tata letak bisa diuji tanpa membaca PDF.

**Tech Stack:** Laravel 13, Inertia v3, Svelte 5, Tailwind 4, Fortify, Wayfinder, Pest 5, SQLite. Dependensi baru: `smalot/pdfparser`, `setasign/fpdf`.

**Spec:** `docs/superpowers/specs/2026-11-05-spj-bos-design.md`. Baca bersama rencana ini.

## Global Constraints

- Tiap file PHP baru memakai `declare(strict_types=1);`, tipe lengkap, dan `#[Fillable([...])]` seperti `app/Models/User.php`. Dilarang `$guarded = []`.
- Nama domain berbahasa Indonesia: model singular (`Kegiatan`), tabel plural snake_case (`kegiatans`), tulis `$table` eksplisit kalau pluralisasi Laravel salah (`jenis_berkas`).
- Antarmuka berbahasa Indonesia. Uang disimpan sebagai integer rupiah.
- Controller tipis. Logika di `app/Actions` atau `app/Impor`. Validasi lewat Form Request.
- Semua rute baru di dalam grup `['auth', 'verified']`. Hanya satu pengguna, jadi tidak ada policy per baris; middleware itu dan pendaftaran yang tertutup adalah batasnya.
- Frontend memakai rute Wayfinder (`@/routes`, `@/actions`) dan komponen `@/components/ui`. Tidak ada `v-html`/`{@html}`.
- PDF asli pemilik dan fotonya tidak boleh di-commit.
- Jangan bergantung pada fitur khusus SQLite (kecuali cadangan di Task 12), program sistem, atau worker antrean. Hosting: akun Hostinger `u641051348` tampaknya hosting bersama, jadi rancang untuk batas terlemah. Butuh PHP ≥ 8.4 karena `composer.lock`.
- Jalankan sebelum tiap commit: `vendor/bin/pint --dirty`, `vendor/bin/phpstan analyse`, `php artisan test --compact`. Task dengan Svelte juga `npm run types:check`.
- Kerjakan di cabang `feat/spj-bos`.

Temuan percobaan yang menentukan parser (posisi dalam satuan PDF, berlaku di semua halaman contoh; toleransi baris ±1,5):
- Jangan pakai `getText()`: angka menempel, misalnya `095.760.000`.
- Jangkar baris: token `x < 60` dengan pola `^\d+\.$`.
- Kolom: kode rekening pola `^\d(\.\d+){5}$`; kode program `x` 160–205 digabung tanpa spasi dan titik terakhir dibuang (`04. 06. 03.` menjadi `04.06.03`); uraian `x` 205–565; volume `x` 571–622; satuan `x` 622–690; tarif `x` 690–780; jumlah `x > 780`.
- Baris uraian ditempelkan ke jangkar terdekat di halaman yang sama (selisih y terkecil), karena potongan uraian muncul di atas dan di bawah baris angka.
- Hanya baris berkode rekening yang menjadi kegiatan. Total dokumen: token `Jumlah` dengan `x < 600`, nilainya token `x > 780` di baris itu.
- Kepala dokumen: nilai `x ≈ 135` pada baris berlabel `NPSN`, `Bulan`, `Sumber Dana`.

  - `SimpanAnggaran::bandingkan(AnggaranTerbaca): RingkasanImpor` dan `SimpanAnggaran::simpan(AnggaranTerbaca, string $namaFile): RingkasanImpor`.
  - `readonly RingkasanImpor(Sekolah $sekolah, ?int $bulan, int $tahun, int $jumlahKegiatan, int $total, int $baru, int $berubah, int $hilang)`
  - Rute: `impor.index`, `impor.pratinjau` (POST, `files[]`, PDF maks 10 MB), `impor.simpan` (POST, `tokens[]`).

Aturan `simpan`, dalam satu transaksi:
- Sekolah dari `identitas`; tidak dikenal atau sistem tidak sesuai → `ImporDitolak`. ARKAS dengan sumber dana selain `BOSP Reguler` → `ImporDitolak`.
- `kunci_impor` = `sha1(kode|kodeProgram|uraian)` + `#` + urutan kemunculan dalam dokumen (kode dan uraian bisa sama, contoh dua "Jendela Aluminium/Kayu"). `periode_impor` = bulan ARKAS atau 0 ERKAM.
- `nama` = ARKAS: uraian sebelum `-` pertama; ERKAM: uraian sebelum ` | `.
- Rutin ERKAM (`^(\d+) bulan$`): satu baris per bulan mulai bulan pertama tahap (Tahap I Januari, Tahap II Juli), `kunci_impor` ditambah `@bulan`, `jumlah = harga`. `N × harga ≠ jumlah` atau melewati bulan terakhir tahap → `ImporDitolak`.
- Sekali belanja ERKAM: `bulan = null`.
- Pembaruan: yang cocok memperbarui `uraian`, `nama`, `koefisien`, `harga`, `jumlah`, `hilang_dari_anggaran = false`; `bulan` kegiatan sekali belanja, jenis, status manual, acara, kuitansi, dan foto tidak disentuh.
- Yang hilang: tanpa kuitansi, foto, dan status manual → dihapus; selain itu `hilang_dari_anggaran = true`.

Alur layar: unggah → file disimpan sementara di `impor-sementara/{uuid}.pdf` pada disk privat → tampil pratinjau per file (sekolah, periode, jumlah kegiatan, total, baru/berubah/hilang) atau pesan penolakan → tombol Simpan. Setiap pratinjau menghapus file sementara berumur > 1 hari.
