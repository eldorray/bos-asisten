# Draf RKAS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modul "Draf RKAS" di bos-asisten untuk menyusun kertas kerja RKAS SMP Garuda dengan mekanisme ARKAS (struktur, perhitungan, validasi, revisi), mulai dari RKAS 2027.

**Architecture:** Tabel sendiri berawalan `rkas_`, model di `app/Models`, logika di `app/Actions/Rkas` (Action + DTO readonly), controller tipis di `app/Http/Controllers/Rkas`, halaman Inertia di `resources/js/pages/rkas`, komponen di `resources/js/components/rkas`. Modul hanya membaca `sekolahs` dan `kegiatans`, tidak pernah menulis ke tabel SPJ.

**Tech Stack:** Laravel 13, PHP 8.4, Inertia v3, Svelte 5 (runes), Tailwind 4, shadcn-svelte, Wayfinder, Pest 5, SQLite, setasign/fpdf, smalot/pdfparser (untuk tes PDF).

**Spec:** `docs/superpowers/specs/2026-11-08-draf-rkas-design.md`. Analisis ARKAS: `/Users/elfahmie/Documents/Coding/rea/analysis/ARKAS-RKAS-MECHANISM.md`.

## Global Constraints

- `declare(strict_types=1);` di setiap file PHP baru. Model memakai `#[Fillable([...])]` dan method `casts()`. PHPDoc array shape untuk parameter array.
- Tidak menambah dependensi dan tidak membuat folder dasar baru (AGENTS.md:30-31). Subfolder di folder yang sudah ada boleh.
- Uang dalam rupiah bulat (`unsignedBigInteger`), tidak pernah float. Persentase dihitung dari bilangan bulat, lalu dibulatkan 2 desimal hanya saat ditampilkan.
- Kode tidak bergantung pada fitur khusus SQLite. Tidak memakai worker antrean.
- Semua rute di dalam grup `auth,verified` di `routes/web.php`. Semua input lewat Form Request. Props Inertia hanya berisi kolom yang dipakai.
- Modul tidak menulis ke `kegiatans`, `kuitansis`, `impor_anggarans`, `acaras`, `fotos`, `jenis_*`, maupun `sekolahs`.
- Kertas kerja hanya untuk sekolah dengan `sistem = SistemAnggaran::Arkas`.
- Tidak ada kode, aset, logo, atau template ARKAS di repo. File `arkas.db` asli tidak pernah di-commit, dan fixture hanya data samaran.
- Pesan pengguna diambil dari `App\Actions\Rkas\PesanRkas` (Task 1). Tes membandingkan dengan konstanta itu, bukan dengan salinan teks.
- Penamaan Indonesia, mengikuti file saudara: Action dengan method kata kerja, tes `it('…')` berbahasa Indonesia.
- Setiap task diakhiri dengan `composer lint` dan tes file task itu hijau. Task terakhir menjalankan `composer ci:check`.

## Review Focus

1. **Pagu 0 atau kertas kerja tanpa baris:** persentase juknis dan jenis belanja harus bernilai 0, tidak boleh error pembagian nol, dan ringkasan tetap tampil. Tes di Task 6.
2. **Baris tanpa volume di bulan mana pun:** ditolak dengan `PesanRkas::VOLUME_KOSONG`, karena jumlahnya 0 dan baris semacam itu tidak berarti di ARKAS. Tes di Task 5.
3. **Revisi kedua saat revisi sebelumnya belum disahkan:** ditolak dengan `PesanRkas::REVISI_TERBUKA`. Satu rantai hanya boleh punya satu versi yang belum disahkan. Tes di Task 8.
4. **Referensi yang dipakai baris dihapus atau kedaluwarsa setelah baris dibuat:** hapus ditolak, kedaluwarsa menandai baris (bukan menghapusnya), dan baris tetap bisa dibuka serta diedit. Tes di Task 3 dan Task 6.
5. **Kertas kerja untuk MI (ERKAM) atau tahun/sumber dana ganda:** ditolak dengan pesan jelas. Kertas kerja aktif (versi awal) tidak boleh ganda per sekolah × tahun × sumber dana. Tes di Task 4.
